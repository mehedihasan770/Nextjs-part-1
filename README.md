# Shop3D

**Shop3D** is a web application for browsing and managing 3D models. Users can explore 3D items, add new products, and manage existing products easily.

## Features
- Browse all 3D products
- Add new 3D products
- Manage (edit/delete) existing products
- View product details

## Pages / Routes
- **Home** (`/`)
- **All Products** (`/all_products`)
- **Add Product** (`/add_product`)
- **Manage Products** (`/manage_products`)
- **Product Details** (`/details/[id]`)
